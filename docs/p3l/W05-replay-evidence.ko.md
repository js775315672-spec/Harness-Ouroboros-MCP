# W05 · 독립 재검증과 증거 기록

**목표** — 다른 러너가 같은 후보를 판정했다는 사실을 커밋과 바이트 수준에서 확인할 수 있게 한다.

**범위** — 새 파일 `scripts/ledger_replay_evidence.py`와 `tests/test_ledger_replay_evidence.py`를 맡는다. 기존 `replay`와 `ci_attestation.py`의 증거 형태를 참고한다. 실행 ID, 기준·후보·응답·diff SHA, 검사 사본의 SHA, 정적 판정, 묶음별 실행 수와 결과를 검증한다. W03 진단은 별도 키에 기록하고 W06과 W07에 결과 형식을 공유한다.

**완료 기준** — SHA, 대상 경로, 검사 수, 판정, 러너 또는 실행 ID가 다른 위조·누락 기록을 거부한다. 기준선과 후보 결과를 분리하고, 같은 요약 상태여도 묶음별 결과가 불일치하면 실패한다. 모델 작업 종료와 최종 후보 통과를 증거에서 구분한다.

**보고** — 필수 필드, 재검증 명령, 합격·거부 예시, 아티팩트 만료 뒤에도 남길 증거 링크와 SHA를 남긴다.
