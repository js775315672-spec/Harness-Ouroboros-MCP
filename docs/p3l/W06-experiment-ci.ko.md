# W06 · 실험 실행과 CI

**목표** — 다음 실험을 한 번 실행하고 실패도 재현 가능한 형태로 보존한다.

**범위** — 새 워크플로 `.github/workflows/ledger-next-experiment.yml`와 `tests/test_ledger_next_workflow.py`를 맡는다. P3k를 기준으로 정확한 소스를 자격 증명 저장 없이 체크아웃하고, 고정된 모델과 같은 실행에서 검증된 바이너리를 사용한다. PR 개설이나 문서 변경으로 모델 호출이 중복되지 않게 한다. 모델 실행과 독립 검증을 별도 러너에서 수행한다.

**완료 기준** — 사전검사와 기준선 실패 재현이 성공해야 추론이 시작된다. 추론 호출은 한 번이고, 후보 실행은 기존 격리 Docker 경계를 따른다. 25개 고정 검사가 실행됐을 때 모두 통과하고 별도 러너가 같은 판정을 내린 경우 최종 게이트가 성공한다. 인프라 실패, 정적 거부, 후보 테스트 실패를 구분해 아티팩트와 로그를 남긴다.

**보고** — 정확한 커밋과 실행 URL, 모델·실행기 해시, 호출 수, 작업별 결과, 실패 시 상태를 남긴다. 실제 호출은 W02·W04·W05 산출물을 통합 검수한 커밋에서 시작한다.
