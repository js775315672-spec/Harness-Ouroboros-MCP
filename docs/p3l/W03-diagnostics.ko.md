# W03 · 규칙별 회귀 진단

**목표** — 잘못된 이유로 발생한 예외가 다른 검증 규칙의 성공으로 집계되지 않도록 별도 진단을 만든다.

**범위** — 새 파일 `tests/test_ledger_rule_diagnostics.py`를 맡는다. `change`를 검증하는 경우 적법한 비어 있지 않은 `fixes`를 사용한다. `fixes`를 검증하는 경우 `change`를 정상으로 고정한다. 정상 빈 목록, 빈 문자열 원소, NUL·줄바꿈, 항목 12/13개와 UTF-8 바이트 경계를 각 필드의 대조 사례로 검사한다.

**완료 기준** — 기존 소스와 P3k 후보의 알려진 차이에서 어떤 규칙이 실패하는지 별도 로그로 설명할 수 있다. P3k에서처럼 정상 빈 목록을 거부하는 구현은 해당 정상 사례에서 실패한다. 기존 25개 검사와 진단 결과는 각각 실행·보고한다.

**보고** — 사례별 입력 조건, 예상·실제 판정, 원본 또는 후보 SHA, 명령을 남긴다. 새 진단을 공식 합격 조건으로 편입하는 변경은 후속 검수에서 결정한다.
