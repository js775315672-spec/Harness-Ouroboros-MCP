# W07 · 후보 승격과 이전 버전 복구

**목표** — 검증된 모델 패치를 다음 실행기 버전 후보로 연결하고 실패 시 돌아갈 수 있게 한다.

**범위** — `scripts/ledger_candidate_promotion.py`와 `tests/test_ledger_candidate_promotion.py`를 맡는다. 기존 `scripts/model_task_queue_bridge.py`와 체크포인트 구조를 참고한다. 입력은 W05 검증 기록, 후보 커밋, 이전 실행기 커밋, 해당 후보의 전체 Harness CI다. 시험용 버전 전환 경로에서 검증한다.

**완료 기준** — 25개 후보 검사와 독립 재검증 및 정확한 후보 커밋의 CI가 확인돼야 승격 후보를 만든다. 전환 중 실패한 경우 이전 SHA가 남고, 재시도해도 중복 승격되지 않는다. 새 실행기가 실패하면 이전 커밋으로 돌아가 이후 작업을 그 커밋에서 시작할 수 있음을 검증한다.

**보고** — 이전/후보/활성 SHA, 검증 링크, 실패 또는 재시작 절차, W08에 넘길 인계 기록 형식을 적는다.
