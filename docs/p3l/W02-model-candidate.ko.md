# W02 · 모델 입력과 후보 생성

**목표** — 원본 함수와 검증된 계약만으로 모델이 새 원장 후보를 작성하게 한다.

**범위** — `scripts/p3g_qwen_ledger_feedback_repair.py`의 프롬프트 구성·모델 호출 부분과 해당 단위 검사를 맡는다. W01의 계약을 바탕으로 빈 목록과 빈 원소, 개수 제한과 항목별 바이트·제어문자 제한을 구분해 전달한다. 입력은 원본 함수와 실패 동작 요약을 사용하고, 기존 실패 코드 전문과 검사 구현은 프롬프트에서 제외한다. 실행 기록에는 모델 리비전, 입력 SHA, 원본 SHA, 생성 설정을 남긴다.

**완료 기준** — 기록을 재생하면 같은 프롬프트 바이트가 나온다. 프롬프트 조건을 검사하는 테스트와 모델 대역을 사용한 후보 생성 테스트가 통과한다. 실제 모델 호출은 W06 검증 경로를 통해 한 번 실행한다. 모델이 반환한 패치를 그대로 `validate(records)` 한 함수에만 적용한다.

**보고** — 기존 입력과 다른 부분, 프롬프트 SHA, 출력 형태와 변경 경로를 적는다. W04와 겹치는 검사·재시도 코드는 직접 바꾸기 전에 변경 위치를 검수자에게 알린다.
