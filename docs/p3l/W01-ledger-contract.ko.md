# W01 · 원장 입력 계약

**목표** — 모델과 검수자가 같은 입력에 같은 판정을 내릴 수 있도록 `validate(records)` 계약을 명세한다.

**범위** — `docs/p3l/ledger-input-contract.ko.md`를 작성한다. 현재 원장 코드, P3k diff, 고정 검사 정의를 대조한다. 연속 사이클, 정확한 커밋·CI 링크·검사 상태, 데이터 불변을 포함한다. `fixes=[]` 허용, 빈 문자열 원소 거부, 최대 12개, 원소당 최대 128 UTF-8 바이트, `change` 최대 256 UTF-8 바이트와 제어문자 제한을 표에 적는다. 문자 수와 바이트 수가 다른 한글 경계를 보여준다. 공백만 있는 문자열처럼 정책이 불명확한 경우 기존 동작과 결정을 구분해 검수 요청한다.

**완료 기준** — 각 규칙에 정상 입력과 거부 입력이 한 쌍 이상 있고, 나머지 필드는 유효하게 고정된다. P3k의 정상 빈 목록 회귀를 표에서 찾을 수 있다. 원장 구현, 모델 출력, 고정 검사 25개에는 변경이 없다.

**보고** — 사례 표, 논쟁이 남은 한계, W02에 줄 짧은 계약과 W03에 넘길 경계 사례를 PR에 기록한다.
