# W08 · 다음 세대의 후속 작업

**목표** — 승격 후보의 Harness가 기존 원장 과제와 다른 일을 스스로 골라 패치를 제출하는지 검증한다.

**범위** — `scripts/task_selector.py`, `scripts/development_coordinator.py`의 연결과 해당 검사를 맡는다. `scripts/resumable_task_queue.py`의 큐 계약은 재사용한다. 허용된 과제 후보, 선택 근거, 기준 커밋, 수정 가능 파일, 시간·호출 한도, 수용 검사를 실행 요청에 고정한다.

**완료 기준** — 대역 테스트에서 승격 기록을 확인하고 후속 과제 한 개를 고른 뒤 후보 패치를 감독자에게 제출한다. 중단된 실행에서는 과제를 완료 처리하거나 중복 제출하지 않는다. 실제 단계에서는 W07의 검증된 새 SHA에서 모델이 작성한 새 패치를 독립 검증하고, 이전 원장 패치의 재생으로 성공 횟수를 올리지 않는다.

**보고** — 선택된 과제와 근거, 승격 실행기 SHA, 모델 패치 SHA, 재개·중지 결과를 남긴다. 실제 승격 후보가 오기 전 대역 결과임을 표시한다.
