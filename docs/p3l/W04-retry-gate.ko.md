# W04 · 반복 후보와 재시도 제어

**목표** — 같은 구현 반복, 무변경 후보, 예산 소진 후의 추가 추론을 차단한다.

**범위** — `scripts/model_stagnation_gate.py`, `tests/test_model_stagnation_gate.py`를 맡는다. 동일 응답 바이트와 동일 함수 AST를 별도로 비교한다. 기존 순수 판단기와 P3k의 함수 해시를 대조하고, 재시도 상태를 과제·기준 소스·모델·프롬프트의 고정 값에 결합하는 인터페이스를 제안한다. 과거 기록은 호환 입력으로 다룬다.

**완료 기준** — 동일한 출력, 공백만 달라진 AST, 다른 기준 SHA의 기록, 무변경, 예산 소진, 이미 통과한 후속 호출을 테스트한다. 역사적으로 확인된 실패 AST의 차단과 실행 이력 판정은 추가 권한 없이 동작한다. 재시도 허용 결과는 한 번의 호출 제안만 반환한다.

**보고** — 허용과 중단의 예시, 의사결정 이유, W02·W06이 호출할 인터페이스를 남긴다. 공용 실행기로 옮길 연결부는 통합 검수에서 결정한다.
