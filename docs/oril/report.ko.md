로컬에서 확인된 해당 프로젝트 예약은 일시 정지된 `harness-ouroboros-8`이었다. 나머지 네 예약의 실제 소유권·실행 상태를 확인할 자료는 발견하지 못했다. 통합 Actions 워크플로는 같은 워크플로·head·base의 최초 실행을 정식 소유자로 선택하고 동일 head의 실행을 직렬화한다. GitHub가 현재 실행을 원장 조회에 반환하지 않으면 중단한다. 이 보장은 통합 워크플로를 이용한 작업에 적용된다.

### 재시작과 예산

실패한 Actions 작업은 같은 run ID에서 재시도한다. 기존 `raw-N`과 `review-N` 아티팩트는 재사용하며 만료되거나 중복된 체크포인트는 오류로 처리한다. 사이클당 모델 호출은 120회, 캠페인은 3사이클, 시도 상한은 3이다. 호출 중 중단되어 아티팩트가 발행되지 않은 단계는 재시도 때 일부 호출을 반복할 수 있다. 작업별 시간 상한은 추론 22분, 검산 4분이다. 저장소 변수 `ORIL_STOP=true`로 다음 추론 작업을 중단할 수 있다. 이미 실행 중인 작업은 Actions의 취소 기능을 사용한다. 비용의 화폐 환산과 서비스 계정별 과금 정보는 미측정이다.

실행 증거는 아래 두 원장에서 확인할 수 있다. 각 원장에는 원시·검산 ZIP의 GitHub artifact ID·SHA256·작업 ID·시각이 들어 있다. ZIP에는 각 사이클의 실제 입력, 프롬프트 내용 SHA256, 원시 생성 문자열과 토큰·지연시간, 검산 결과와 정답을 제외한 후속 메모리가 있다. `candidate_sha`는 프롬프트 바이트의 SHA256이며 코드 커밋은 `implementation_sha`다.

### 공개 검산과 보호된 판정

감사 작업은 추론과 다른 GitHub 러너에서 `f32dd7cc8b6e71995ae2c182ad6cc25c22ca0bdb`에 고정된 공개 감사기를 체크아웃한다. 공개 정답, 정확도, 토큰, 지연 중앙값과 A/A 통계를 원시 관측에서 재계산한다. 별도 재생 검사는 아카이브 SHA, 부모 메모리 바이트, 후보 프롬프트 SHA, 가설 선택, 모델·데이터 식별자와 후속 검산 결과를 확인한다. 지정된 출력과 검산 결과를 함께 위조하는 공격에 대한 신뢰 근거는 GitHub가 발행한 아티팩트 digest와 고정된 실행 기록이다. 개발자가 관리하는 PR은 비공개 합격 판정의 신뢰 기반으로 사용할 수 없다.

비공개 `oril-private-verifier`의 확인된 기본 워크플로는 기준선 검사이며 후보 입력을 받지 않는다. 연결 계정에는 해당 저장소 쓰기 권한이 있다. 독립 검증자의 별도 자격 증명·보호 규칙과 후보용 진입점이 있어야 P4를 실증할 수 있다. 정답·비밀 데이터 열람, 검증기 변경, 운영 승인·배포는 수행하지 않았다. 전달 가능한 후보의 식별자와 공개 성적은 이 보고서에 수록했다.
