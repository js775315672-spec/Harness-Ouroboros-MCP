# P2d — 검토·보완한 실제 저장소 소스 패치

## 출처와 기여의 경계
첫 번째 Qwen2.5-Coder-7B 실제 모델 출력(P2a run 43842525152)은 scripts/agent_handoff.py의 기존 handoff 함수 전체 수정안을 생성하고, 기존 회귀 13개와 새 보안 검증 10개 중 8개를 통과했다. 모델 후보는 앞/뒤 공백 검사를 누락해 **실패**했다. 독립 재검증도 불합격을 재현했다.

Qwen 피드백 재수정(P2b, P2c)도 각각 **실패**했다. 두 모델은 문자열의 모든 공백을 거부해 정상적인 다단어 작업이 오류로 처리됐다. 따라서 **어떤 단독 Qwen 소스 패치도 23/23을 통과하지 못했다.**

이번 소스 변경에는 **어시스턴트의 검토·보완으로 첫 번째 모델 코드에 task != task.strip() 검증을 추가**했다. 따라서 이 커밋은 모델이 독립적으로 작성·검증·푸시한 개발 결과가 아니다. 'AI 자율개발 성공'으로 분류하지 않는다.

## 실제 변경점
- scripts/agent_handoff.py: 기존 handoff 함수 교체. 기존 승인·읽기전용·브랜치/사이클 정책 유지.
- 작업 지시 문구는 문자열이어야 하고, 공백만 있거나 앞/뒤 공백을 포함하면 거부한다. 일반 단어 사이 공백 및 안전한 한국어는 허용한다.
- 240 UTF-8 바이트 제한, 제어문자 C0/DEL/C1 입력 거부.
- tests/test_agent_handoff_security_p2d.py: **P2a에 미리 동결한 10개 테스트 메서드의 동일 내용**을 전체 테스트 검색 대상으로 승격한다.

## 검증 단계
1. 원래 P2a 기준 소스는 기존 회귀 13/13 합격, 새 보안 테스트에서 13개 실패 하위 사례 발생(negative control).
2. 모델 소스는 8/10 보안 메서드 통과·13/13 기존 회귀 통과, 독립 검증 실패.
3. 이번 코드 패치는 별도 Draft PR에 실제 GitHub 소스 커밋으로 반영한다. **해당 커밋 SHA를 대상으로 GitHub Actions 전체 회귀/보안 CI 성공을 확인해야만 소스 패치 검증 성공**.
4. 이 변경은 모델 외부에서 검토한 것이므로 자동화된 코딩 루프의 자율성 점수 0이다.

## 제한
모델의 코드 실행/쓰기 권한 없음. 실거래, 유료 API, 비밀키, 재귀 작업 발행, 일정 실행, 자동 병합 없음. Draft PR로 유지하며 병합은 별도 승인 필요.

## 개선해야 하는 후속 연구
실제 모델의 신뢰성을 높이려면 P2a~P2c와 별개의 **새로운 저장소 소스 과제와 사전 등록된 홀드아웃**에서, 같은 Qwen이 사람의 함수 수정 없이 패치를 작성·검증하도록 성공 기준을 확장해야 한다.
