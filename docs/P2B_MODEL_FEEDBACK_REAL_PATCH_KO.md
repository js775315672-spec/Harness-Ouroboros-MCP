## 판정 규칙
이번 P2b는 원래 테스트 실패에 맞춰 추가 정보를 제공한 **피드백 기반 재시도**이므로 P1d/P1e처럼 독립된 새 홀드아웃에 대한 일반화 성능 검증이 아님. P2a 실패도 성공으로 변경하지 않음.

같은 오류에 대한 모델 주도 재시도 성공이더라도 아직 **GitHub 실제 코드 커밋 + 해당 SHA 독립 CI** 단계와 다르며, 사전 승인 없이 병합하지 않음. 비밀키, 유료 API, 자동 푸시, 실거래, 예약/재귀 실행은 계속 없음.
