## P3b 새 호출
첫 모델 응답과 본래 함수, 검증된 "코드가 변경되지 않았다"는 실패 피드백을 두 번째 신규 Qwen 호출에 제공한다. 권한 입력 alias 및 비교 연산 스푸핑을 어떻게 다뤄야 하는지 설명하지만 완성된 정답 함수는 제공하지 않는다.

**모델 입력에 새로운 보안 테스트 소스는 포함하지 않는다.** 동일한 기존 23개 회귀 테스트와 새 10개 홀드아웃을 한 글자도 수정하지 않고 사용한다. 변경된 것은 모델 prompt/이전 모델 응답 고정만이다.

승인 기준: Qwen 단독 코드 제안의 AST가 실제 원본과 달라야 하며, 고정된 함수 위치의 unified diff가 생성되어야 함 → 격리 Docker 기존 23/23 + 새 10/10 → 독립 runner의 원본 모델 응답 해시, 소스 SHA, 동일 33개 테스트 재검증 → 필수 candidate_acceptance_gate 통과. 실패한 모델 출력도 보존한다.

## 해석 제한
같은 보안 과제에 대해 실패 피드백을 전달하므로, 성공하더라도 **새로운 과제에서의 일반화 성능 향상으로 해석할 수 없다**. 아직 AI가 GitHub에 직접 코드를 푸시하거나 실행 예약/재귀 task를 발행하지 않음. 비밀키·유료 API·거래·자동 병합·실운영 배포 금지. Draft PR로 유지하며 사용자의 명시적인 병합 승인이 필요함.
