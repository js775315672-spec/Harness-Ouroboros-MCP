## 기준선과 실패를 왜곡하지 않음
- P3f 첫 Qwen7B 실소스 호출: run #43888636930, **모델 응답은 실제로 새 보안 코드를 포함했으나 정적 AST 게이트의 보호변수 문자열 버그로 최초 분류가 거부됨**. 따라서 첫 run을 성공으로 소급 판정하지 않는다.
- 같은 과제의 정적 게이트 오탐을 수정한 run #43890041190: **첫 모델과 동일한 원본 소스 응답 SHA-256 d526bb30b6b5be5cb2baa88ed86977b8a6dcbc4d043e265595a9d3707bad6de7**를 새로운 모델 호출로 생성. 기존 회귀 15/15, 신규 보안 9/10, 총 **24/25 통과**, 독립 러너도 동일 실패를 재현.
- 유일하게 불합격한 홀드아웃 유형: fixes 목록 원소 중 **빈 문자열**을 거부하지 않음. 이는 모델의 검증 누락이지 인프라 버그가 아님.
- 25/25가 아니었으므로 mandatory candidate_acceptance_gate는 최종 빨간색. 실제 GitHub 소스 커밋/모델 단독 성공 0건.

## 이번 모델 피드백 재시도
- 기존 Qwen 첫 출력 원문 1,487바이트를 proposals/p3f_first_qwen_ledger_response.txt에 고정. 원본 응답 SHA-256을 반드시 대조.
- 두 번째 신규 Qwen7B GGUF 호출 1회는 실제 원본 development_ledger.validate(records) 함수와 모델 자신의 24/25 패치, "fixes의 빈 문자열도 거부해야 한다"는 검증 결과 요약을 제공받음. 완성된 정답 함수를 직접 제공하거나 숨겨진 테스트 구현을 보여주지 않음.
- 원래 **15개 회귀 + 10개 숨겨진 보안 테스트 = 25개**는 P3f 사전등록 시점 파일을 그대로 사용하고 수정하지 않음. 기존 원본에서 신규 보안은 빨간색이어야 함.
- 모델은 수정된 전체 validate() 함수 하나만 출력. 정적 안전 AST, 다른 소스 구간 불변 검사, 안전 Docker 격리 테스트, 다른 GitHub 러너의 독립 replay, mandatory 25/25 acceptance gate 순으로 판정.
- 정확한 SHA 및 same-run llama.cpp CPU 빌드 아티팩트를 공유하는 검증된 P3e 구조를 다시 사용함.

## 성과 해석
- P3g 통과 시: 동일 과제에서 **오류 피드백을 제공받은 모델의 제한된 코드 수정 성공**. P3f의 최초 24/25 결과를 덮어쓰거나 "처음 보는 문제의 무피드백 일반화" 성공으로 재분류하지 않는다.
- P3g가 pass 하더라도 모델이 GitHub에 소스 파일을 자동 커밋한 것이 아니며, actual-source SHA CI는 별도 검토·Draft PR로 증명해야 한다.
- 비밀키·유료 API·자동 push/merge·실거래·재귀 8x8 작업 생성 금지.

## P3g 결과와 P3h 후속 실험

[독립 검증 실행 43891791328](https://github.com/js775315672-spec/Harness-Ouroboros-MCP/actions/runs/43891791328)의 P3g 결과는 24/25다. 후보는 `fixes`의 빈 원소를 검사 대상에서 건너뛰었다. 기존 회귀 15개와 나머지 홀드아웃 9개는 통과했다. 최종 게이트는 이 후보를 거부했다.

P3h는 다운로드한 원본 기록과 독립 판정의 SHA-256, P3g 모델 응답과 대상 소스·검사 파일의 SHA-256을 고정한 `proposals/p3h_verified_p3g_failure.json`을 사용한다. 프롬프트에는 실패한 모델 구현과 관측된 동작을 전달한다. 두 이전 후보와 같은 Python 구문 트리는 별도 검사를 시작하기 전에 거부한다. 새 후보는 기존 25개 검사와 별도 러너의 독립 재검증을 통과해야 한다.

기존 P3g 모드를 재현할 때는 기본 CLI를 사용한다. P3h에는 `preflight`, `run`, `replay`에 각각 `--retry-p3g`를 지정한다. P3h 워크플로는 회귀 기준을 검증한 뒤 모델 호출 한 번을 수행한다. 합격한 후보도 별도 커밋·승격 단계가 필요하다.
