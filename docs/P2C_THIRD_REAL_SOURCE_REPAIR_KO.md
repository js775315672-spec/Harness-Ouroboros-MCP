# P2c — 세 번째 Qwen 소스 수정 실험 (인과적 일반화 주장 금지)

- P2b: 첫 실패를 모델에 입력해 새로운 Qwen 7B 추론 1회 수행. 두 번째 모델은 전체 코드 수정안 생성에 성공했지만, 문자 c가 일반 공백 문자이면 어디든 거부하도록 만들었다. 이로 인해 정상 다단어 작업지시가 거부되어 **기존 회귀 테스트까지 실패**.

## 이번 Qwen 추론(세 번째 호출)
기존 저장소 함수+두 번째 실패 모델 응답+이전 2회 실패 요약을 제공한다. 모델은 단일 정답 조각 대신 **원본 handoff 함수 전체를 새로 작성**해야 한다. 정상 내부 공백과 비정상 경계 공백을 구별하고, 제어문자·UTF-8 길이 한도·승인/권한 부여 방지 불변조건을 지켜야 한다.

기존 **13개 회귀 + 새 10개 보안 테스트**는 P2a와 동일하고, 숨겨진 테스트 코드는 여전히 프롬프트에 넣지 않는다. 후보를 한정된 파일의 함수 구간만 수정한 unified diff로 구성한 뒤 비루트/네트워크 차단/읽기 전용 Docker에서 검증한다. 결과를 다른 runner에서 원본 모델 응답 해시·동일 SHA와 비교하여 재검증한다.

## 실패·성공 선언
- 실패한 모델 출력, 잘못된 패치 및 테스트 실패는 모두 추적하고 이전 회차의 실패를 덮어쓰지 않는다.
- P2c 후보가 성공해도 이는 **피드백으로 안내된 동일 문제의 수정 성공**이지 새 홀드아웃 일반화 증거가 아니다.
- 본 실험은 실제 저장소 소스 커밋을 자동 생성하지 않는다. 성공한 후보는 사람 검토/승인 게이트를 거쳐 별도 Draft PR에 실소스 패치로 올리고 커밋 SHA의 전체 CI를 다시 통과시켜야 한다.
- 비밀키·유료 API·GitHub write token·자동 병합·스케줄·재귀 증식·실거래 금지.
